11. Finding the Maximum
Key idea: Set Highest to the first value, then compare every later value against it. Never start at 0 — a list of negative numbers would break.
1Sample Reference
DECLARE Counter, Number, Highest : INTEGER

INPUT Number
Highest <- Number

FOR Counter <- 2 TO 10
  INPUT Number
  IF Number > Highest
    THEN
      Highest <- Number
  ENDIF
NEXT Counter

OUTPUT "The highest number is ", Highest
2Fill in the Space

Highest <- ____

  INPUT Mark

    THEN
      Highest <- ____
  ENDIF
NEXT Counter

OUTPUT "Highest mark is ", ____

13. Linear Search
Key idea: Use a BOOLEAN flag called Found. Start it as FALSE and stop as soon as it becomes TRUE, so you do not keep searching a list you have already finished with.
1Sample Reference
DECLARE Titles : ARRAY[1:20] OF STRING
DECLARE SearchTitle : STRING
DECLARE Counter : INTEGER
DECLARE Found : BOOLEAN

Found <- FALSE
Counter <- 1
INPUT SearchTitle

WHILE Counter <= 20 AND Found = FALSE DO
  IF Titles[Counter] = SearchTitle
    THEN
      Found <- TRUE
    ELSE
      Counter <- Counter + 1
  ENDIF
ENDWHILE

IF Found = TRUE
  THEN
    OUTPUT "Found at position ", Counter
  ELSE
    OUTPUT "Title not found"
ENDIF
2Fill in the Space

7. Functions and Procedures

18. Procedures
Key idea: A PROCEDURE performs a task and does not return a value. It is invoked with the CALL command.
1Sample Reference
PROCEDURE DisplayMessage(Name : STRING)
  OUTPUT "Hello ", Name
ENDPROCEDURE

CALL DisplayMessage("Amy")
2Fill in the Space
____ AddNumbers(Num1 : INTEGER, Num2 : INTEGER)
  OUTPUT Num1 + Num2
____

CALL ____(____, ____)
3Own Pseudocode
Write a PROCEDURE called ShowSquare that receives an INTEGER parameter and outputs its square. Then CALL it.
4Scenario Question
Write a PROCEDURE that receives a student's name and mark, and outputs them as "Name: mark".
19. Functions
Key idea: A FUNCTION always RETURNS a value and is used inside an expression (e.g. an assignment or OUTPUT) — it is never invoked with CALL.
1Sample Reference
FUNCTION Square(Num : INTEGER) RETURNS INTEGER
  RETURN Num * Num
ENDFUNCTION

DECLARE Result : INTEGER
Result <- Square(5)
OUTPUT Result
2Fill in the Space
