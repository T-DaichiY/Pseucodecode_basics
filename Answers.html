// 14. Bubble Sort
Marks[3] <- 72
Marks[4] <- 51

Swap <- FALSE
FOR Index <- First TO Last - 1
  IF Marks[Index] > Marks[Index + 1]
    THEN
      Temp <- Marks[Index]
      Marks[Index] <- Marks[Index + 1]
      Marks[Index + 1] <- Temp
      Swap <- TRUE
  ENDIF
NEXT Index
Last <- Last - 1
UNTIL (NOT Swap) OR Last = 1

Part 2 — MCQ Answer Key

1. Basics

  1. Which keyword declares a variable?

    • INPUT
    • DECLARE
    • OUTPUT
    • NEXT
    DECLARE states variables and data types.

  2. Best data type for a name?

    • INTEGER
    • REAL
    • STRING
    • BOOLEAN
    Names are text, so use STRING.

  3. What does <- mean?

    • Equal to
    • Assignment
    • Not equal
    • End
    <- assigns a value.

  4. Best data type for whole-number age?

    • INTEGER
    • REAL
    • STRING
    • CHAR
    Whole numbers use INTEGER.

  5. Why does sequence matter?

    • It changes names
    • It removes declarations
    • It avoids loops
    • Order affects result
    Algorithms run in order.

2. Selection

  1. Which keyword ends IF?

    • NEXT
    • ENDWHILE
    • ENDIF
    • STOP
    ENDIF closes IF.

  2. Both conditions true?

    • OR
    • AND
    • NOT
    • OTHERWISE
    AND requires both.

  3. Best for menu choices?

    • CASE OF
    • DECLARE
    • OUTPUT
    • LENGTH
    CASE OF handles fixed choices.

  4. Not equal operator?

    • =
    • <=
    • >=
    • <>
    <> means not equal.

  5. Invalid CASE choice?

    • NEXT
    • THEN
    • OTHERWISE
    • INPUT
    OTHERWISE handles other values.

3. Loops

  1. Exactly 10 repetitions?

    • FOR
    • CASE
    • IF
    • DECLARE
    FOR is count-controlled.

  2. Always runs once?

    • FOR
    • WHILE
    • REPEAT UNTIL
    • CASE
    REPEAT UNTIL tests at the end.

  3. May run zero times?

    • REPEAT
    • WHILE
    • OUTPUT
    • CASE
    WHILE tests at the start.

  4. Closes FOR loop?

    • ENDIF
    • ENDCASE
    • UNTIL
    • NEXT Counter
    NEXT closes FOR.

  5. Sentinel value?

    • Stop value
    • Data type
    • Declaration
    • Trace column
    A sentinel stops input.

4. Standard Methods

  1. Total starts at?

    • 0
    • 1
    • 100
    • TRUE
    Totals usually start at 0.

  2. Increment counter?

    • Count <- Count - 1
    • Count <- Count + 1
    • Count <- 0
    • Count <- Total
    Add 1 to Count.

  3. Average formula?

    • Total * Count
    • Count / Total
    • Total + Count
    • Total / Count
    Average is total divided by count.

  4. In a linear search, the flag Found starts as?

    • TRUE
    • FALSE
    • 1
    • 100
    Found starts FALSE and only becomes TRUE when the item is located.

  5. To find the highest value in a list, Highest should be set to...?

    • 0
    • The first value in the list
    • 1000
    • The last value in the list
    Starting at the first value works for every list, including one made only of negative numbers.

  6. Which comparison is used when finding the LOWEST value?

    • IF Number > Lowest
    • IF Number = Lowest
    • IF Number < Lowest
    • IF Number <> Lowest
    Finding the minimum uses < ; finding the maximum uses > .

4a. Linear Search (dedicated quiz)

  1. What causes the search loop to stop early, before reaching the end of the list?

    • The counter reaches zero
    • The Found flag becomes TRUE
    • The array runs out of memory
    • The list is sorted first
    Found is set to TRUE as soon as a match is located, which ends the loop immediately.

  2. What data type must Found be declared as?

    • INTEGER
    • STRING
    • BOOLEAN
    • CHAR
    Found can only hold TRUE or FALSE, so it is a BOOLEAN.

  3. In the worst case, how many comparisons does a linear search need for a 40-item list?

    • 1 comparison
    • 20 comparisons
    • 0 comparisons
    • 40 comparisons
    If the item is last or missing, every one of the 40 items must be checked.

4b. Bubble Sort (dedicated quiz)

  1. What happens to Last after each complete pass through the list?

    • It decreases by one
    • It increases by one
    • It resets back to one
    • It stays exactly the same
    Each pass places the next-largest value correctly, so Last is reduced by one to skip it next time.

  2. What condition ends the REPEAT...UNTIL loop in the sample bubble sort?

    • Index reaches First
    • The array becomes empty
    • No swap was made or Last equals one
    • Temperature exceeds one hundred
    The loop stops once a full pass makes no swaps, or Last has been reduced to one.

  3. Why are two neighbouring elements swapped during a pass?

    • Because they are exactly equal
    • Because they are out of the correct order
    • Because the loop has just finished
    • Because Last has reached zero
    A swap happens whenever an element is greater than the one next to it, fixing the order.

  1. Value between limits?

  2. Blank input check?

  3. Exactly 8 chars?

    • Length
    • Double entry
    • Trace
    Length check counts characters.

  4. Data entered twice?

    • Range
    • Length
    • Double entry
    • CASE
    Double entry verifies matching inputs.

  5. Valid mark 0-100 rejects?

    • 50
    • 0
    • 101
    • 100
    101 is outside the range.

6. Testing and Debugging

  1. Normal data means?

    • Expected valid data
    • Invalid data
    • Boundary outside
    • No data
    Normal data should be accepted.

  2. Extreme values for 0-100?

    • -1 and 101
    • 0 and 100
    • 50 and 60
    • 0 and 101
    Extreme values are valid ends.

  3. Boundary for lower end 0?

    • -1 and 0
    • 0 and 1
    • 99 and 100
    • 100 and 101
    Boundary checks just outside and just inside.

  4. Trace table records?

    • Variable changes
    • Only headings
    • Only code
    • Only comments
    Trace tables record changing values.

  5. Missing keyword after IF?

    • NEXT
    • ENDIF
    • ENDCASE
    • DECLARE
    IF blocks end with ENDIF.

7. Functions and Procedures

  1. What is the key difference between a FUNCTION and a PROCEDURE?

    • A FUNCTION always returns a value; a PROCEDURE does not
    • A PROCEDURE always returns a value; a FUNCTION does not
    • They are exactly the same
    • A FUNCTION cannot take parameters
    A FUNCTION always RETURNS a value; a PROCEDURE performs a task without returning one.

  2. How do you invoke a PROCEDURE named PrintReport?

    • PrintReport()
    • CALL PrintReport()
    • RETURN PrintReport()
    • OUTPUT PrintReport()
    PROCEDUREs are invoked with the CALL command.

  3. Which keyword must appear in a FUNCTION header but never in a PROCEDURE header?

    • CALL
    • RETURNS
    • DECLARE
    • ENDFUNCTION
    RETURNS specifies the data type of the value a FUNCTION sends back.

  4. Which statement sends a value back to the calling code inside a FUNCTION?

    • OUTPUT
    • CALL
    • RETURN
    • INPUT
    RETURN passes the result back and ends the FUNCTION.

  5. A parameter declared BYREF instead of BYVAL means...?

    • The parameter is optional
    • Changes made inside the subroutine also change the original argument
    • The parameter must be a STRING
    • The subroutine cannot use the parameter
    BYREF passes a reference so changes affect the original variable; BYVAL passes a copy.
